# Whisperwing

Локальный ассистент для рабочих созвонов. Слушает системный звук (собеседников в Zoom/Meet), распознаёт речь в реальном времени и по горячей клавише объясняет, о чём шла речь — полезно, когда всплывает незнакомый контекст (мед. термины, дизайн-жаргон и т.п.) и не хочется тормозить встречу вопросами.

> Использование подразумевает, что все участники созвона знают, что ты пользуешься ассистентом.

## Как это работает

```
Динамики (WASAPI loopback)
        │
        ▼
  recorder (сырой поток)
        │
        ▼
  VAD-сегментер (webrtcvad)
  режет звук по паузам в речи,
  а не по фиксированному времени
        │
        ▼
  faster-whisper
  распознаёт каждый сегмент
        │
        ▼
  ConversationBuffer
  скользящее окно последних N минут
        │
        ▼
  Ctrl+Shift+E → LLM (Ollama / Claude)
  объясняет контекст последних минут разговора
```

## Стек

- **Захват звука**: `pyaudiowpatch` (WASAPI loopback, без установки виртуальных аудиокабелей)
- **Нарезка речи**: `webrtcvad-wheels` — определяет границы фраз по паузам
- **Распознавание**: `faster-whisper` (модель `base`, локально, CPU)
- **LLM**: абстракция с двумя реализациями — `ollama` (бесплатно, локально) и `anthropic` (Claude API, платно после пробных кредитов), переключается через `.env`
- **Хоткеи**: `keyboard` (глобальный хук на уровне ОС)

## Установка

```bash
poetry install
```

### Ollama (бесплатный локальный вариант)

1. Установи с [ollama.com/download](https://ollama.com/download)
2. Скачай модель:
   ```bash
   ollama pull qwen2.5:7b
   ```

### Claude API (опционально, платно после пробных $5)

Получи ключ на [console.anthropic.com](https://console.anthropic.com) → Settings → API Keys.

### `.env`

Создай в корне проекта:

```
LLM_PROVIDER=ollama
ANTHROPIC_API_KEY=
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=qwen2.5:7b
```

## Запуск

```bash
poetry run whisperwing
```

Пока скрипт работает — он непрерывно слушает и распознаёт звук с динамиков. В любой момент нажми **Ctrl+Shift+E**, чтобы получить объяснение последних ~5 минут разговора от LLM. Останови через `Ctrl+C`.

## Структура проекта

```
src/
  config.py              # все настройки в одном месте
  audio_capture.py        # захват звука с loopback-устройства
  vad_segmenter.py        # нарезка звука на фразы по паузам (VAD)
  transcriber.py           # faster-whisper: распознавание речи
  conversation_buffer.py   # скользящий буфер транскрипта
  hotkeys.py                # глобальный хоткей → запрос к LLM
  main.py                    # сборка пайплайна
  llm/
    base.py                    # интерфейс LLMClient + системный промпт
    ollama_client.py            # реализация через Ollama
    anthropic_client.py          # реализация через Claude API
    factory.py                    # выбор провайдера из .env
```

## Настройка под свою область

В `config.py` есть `WHISPER_INITIAL_PROMPT` — список терминов, которые Whisper должен ожидать (сейчас — общие бэкенд/технические). Дополни его специфичными для твоих созвонов терминами (медицина, дизайн, домен продукта) — это заметно улучшает распознавание англицизмов и аббревиатур, которые иначе транскрибируются "на слух" русскими буквами.

## Roadmap

- [x] Захват системного звука (WASAPI loopback)
- [x] Распознавание речи в реальном времени (faster-whisper)
- [x] Нарезка по паузам вместо фиксированного времени (VAD)
- [x] Скользящий буфер разговора
- [x] Хоткей → объяснение через LLM (Ollama / Claude, переключаемо)
- [ ] **Старт/стоп хоткей** — включать прослушивание вручную на время созвона, а не держать скрипт запущенным постоянно
- [ ] **Захват области экрана по хоткею** — выделить регион → отправить в vision-модель (Claude/локальная) с вопросом "что здесь на диаграмме/макете"
- [ ] **Overlay UI** — компактное окно поверх остальных, показывающее текущий буфер и последний ответ LLM, вместо чтения из консоли
- [ ] **Персистентность промптов** — разные `initial_prompt`/словари терминов под разные команды (мед, дизайн), переключаемые без правки кода
- [ ] **Улучшение качества на стыке языков** — сейчас английские аббревиатуры в русской речи распознаются нестабильно даже с `initial_prompt`, возможно стоит попробовать более крупную модель (`small`/`medium`) или fine-tune словаря
- [ ] **История сессий** — сохранять транскрипт и ответы LLM в файл/базу для последующего просмотра после созвона
