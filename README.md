# Whisperwing

Локальный ассистент для рабочих созвонов. Слушает системный звук (собеседников в Zoom/Meet), распознаёт речь в реальном времени и по горячей клавише или кнопке в overlay-панели объясняет, о чём шла речь — полезно, когда всплывает незнакомый контекст (мед. термины, дизайн-жаргон и т.п.) и не хочется тормозить встречу вопросами. Также умеет объяснять содержимое выделенной области экрана (диаграммы, макеты) через vision-модель.

> Использование подразумевает, что все участники созвона знают, что ты пользуешься ассистентом.

## Как это работает

```
Динамики (WASAPI loopback)
        │
        ▼
  recorder (сырой поток, активен только когда прослушивание включено)
        │
        ▼
  VAD-сегментер (webrtcvad)
  режет звук по паузам в речи,
  а не по фиксированному времени
        │
        ▼
  faster-whisper
  распознаёт каждый сегмент
        │
        ▼
  ConversationBuffer
  скользящее окно последних N минут
        │
        ├── Ctrl+Shift+E / кнопка "Объяснить" → LLM объясняет контекст разговора
        │
        └── Ctrl+Shift+S / кнопка "Экран" → выделяешь область мышью →
            скриншот + контекст разговора → vision-LLM объясняет изображение

Всё это отображается в overlay-панели (PyQt6), поверх остальных окон,
можно двигать и менять прозрачность.
```

## Стек

- **Захват звука**: `pyaudiowpatch` (WASAPI loopback, без установки виртуальных аудиокабелей)
- **Нарезка речи**: `webrtcvad-wheels` — определяет границы фраз по паузам
- **Распознавание**: `faster-whisper` (модель `base`, локально, CPU)
- **Захват экрана**: `mss` + `Pillow`, выделение области — окно на `tkinter`
- **LLM**: абстракция с двумя реализациями — `ollama` (бесплатно, локально) и `anthropic` (Claude API, платно после пробных кредитов), переключается через `.env`. Поддерживает и текст, и изображения (vision)
- **UI**: `PyQt6` — overlay-панель поверх остальных окон, перетаскиваемая, с регулировкой прозрачности
- **Хоткеи**: `keyboard` (глобальный хук на уровне ОС, работает независимо от фокуса окна)

## Установка

```bash
poetry install
```

### Ollama (бесплатный локальный вариант)

1. Установи с [ollama.com/download](https://ollama.com/download)
2. Скачай текстовую модель:
   ```bash
   ollama pull qwen2.5:7b
   ```
3. Скачай vision-модель (для объяснения скриншотов):
   ```bash
   ollama pull llava:7b
   ```

### Claude API (опционально, платно после пробных $5)

Получи ключ на [console.anthropic.com](https://console.anthropic.com) → Settings → API Keys.

### `.env`

Создай в корне проекта:

```
LLM_PROVIDER=ollama
ANTHROPIC_API_KEY=
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=qwen2.5:7b
OLLAMA_VISION_MODEL=llava:7b
```

## Запуск

```bash
poetry run whisperwing
```

Открывается overlay-панель. Прослушивание звука **выключено по умолчанию** — включи его перед созвоном.

| Действие | Хоткей | Кнопка в панели |
|---|---|---|
| Вкл/выкл прослушивание | `Ctrl+Shift+L` | ▶ Слушать / ⏸ Остановить |
| Объяснить последние минуты разговора | `Ctrl+Shift+E` | 💬 Объяснить |
| Выделить область экрана и объяснить | `Ctrl+Shift+S` | 🖼 Экран |

Хоткеи глобальные — работают, даже когда фокус на другом окне (например, на Zoom). При включении прослушивания старый буфер очищается — каждая сессия начинается с чистого листа.

## Структура проекта

```
src/
  config.py              # все настройки в одном месте
  audio_capture.py        # захват звука с loopback-устройства
  vad_segmenter.py        # нарезка звука на фразы по паузам (VAD)
  transcriber.py           # faster-whisper: распознавание речи
  conversation_buffer.py   # скользящий буфер транскрипта
  screen_capture.py         # выделение области экрана + скриншот
  signals.py                 # Qt-сигналы для связи фоновых потоков с UI
  actions.py                  # общая логика для хоткеев и кнопок overlay
  overlay.py                   # overlay-панель (PyQt6)
  hotkeys.py                    # регистрация глобальных хоткеев
  main.py                        # сборка пайплайна, Qt event loop
  llm/
    base.py                        # интерфейс LLMClient + системные промпты
    ollama_client.py                 # реализация через Ollama (текст + vision)
    anthropic_client.py               # реализация через Claude API (текст + vision)
    factory.py                         # выбор провайдера из .env
```


## Настройка под свою область

В `config.py` есть `WHISPER_INITIAL_PROMPT` — список терминов, которые Whisper должен ожидать (сейчас — общие бэкенд/технические). Дополни его специфичными для твоих созвонов терминами (медицина, дизайн, домен продукта) — это заметно улучшает распознавание англицизмов и аббревиатур, которые иначе транскрибируются "на слух" русскими буквами.
